# ERP 系统本地服务器部署（Cloudflare Tunnel）步骤

目标：把你本地服务器上运行的 ERP 系统，通过 Cloudflare Tunnel 安全暴露到公网，
用网址 **https://chinamxl.cc.cd** 访问。

> 前提（你已确认就绪）：本地服务器已安装 `cloudflared`，且你的 Cloudflare 账号下
> 已托管域名 `chinamxl.cc.cd`（或它的上级域 `cc.cd`）并已接入 Cloudflare。

---

## 第一步：登录 Cloudflare（生成证书）

在本机（本地服务器）打开命令行（PowerShell 或 CMD）执行：

```powershell
cloudflared login
```

- 会自动打开浏览器，让你登录 Cloudflare 并选择域名 `chinamxl.cc.cd` 所属的账号；
- 确认后，会在 `C:\Users\Administrator\.cloudflared\cert.pem` 生成证书。

---

## 第二步：创建隧道（这一步会生成你要的 JSON 凭证文件）

```powershell
cloudflared tunnel create erp-tunnel
```

执行成功后你会看到类似输出：

```
Tunnel with name erp-tunnel has been created.
You can now route traffic to it using:
  cloudflared tunnel route dns erp-tunnel chinamxl.cc.cd
```

**关键点**：这条命令会在以下位置自动生成你要的「JSON 凭证文件」：

```
C:\Users\Administrator\.cloudflared\<隧道ID>.json
```

这个文件就是部署平台/隧道运行所必须的凭证，里面包含：
- 账户 ID（AccountTag）
- 隧道 ID（TunnelID）
- 隧道名称（TunnelName）
- 隧道密钥（TunnelSecret，Cloudflare 生成，无法伪造）

> 注意：该文件由 Cloudflare 下发，**无法手动编写**，必须走 `cloudflared tunnel create`。
> 它含密钥，请勿外泄、不要提交到 git。

记下输出里的隧道 ID（一串形如 `a1b2c3d4-...` 的 uuid）。

---

## 第三步：确认隧道 ID

```powershell
cloudflared tunnel list
```

复制你刚创建的 `erp-tunnel` 对应的 ID。

---

## 第四步：填写配置文件

打开本项目里的 `cloudflare\config.yml`，把两处 `<TUNNEL_ID>` 都替换成第三步记下的真实隧道 ID。

例如替换后：

```yaml
tunnel: a1b2c3d4-1234-5678-9abc-def012345678
credentials-file: C:\Users\Administrator\.cloudflared\a1b2c3d4-1234-5678-9abc-def012345678.json
```

然后把填好的 `config.yml` 放到默认位置：

```powershell
copy "D:\demo\ERPGo_API版本\cloudflare\config.yml" "C:\Users\Administrator\.cloudflared\config.yml"
```

（或保持在本项目目录，运行时用 `--config` 指定路径也行。）

---

## 第五步：把域名指向隧道（DNS）

```powershell
cloudflared tunnel route dns erp-tunnel chinamxl.cc.cd
```

这会在 Cloudflare 自动添加一条 `chinamxl.cc.cd` 的 CNAME 记录，指向你的隧道。

---

## 第六步：启动隧道

```powershell
cloudflared tunnel run erp-tunnel
```

看到 `Connected to Cloudflare` 之类日志即成功。

> 若 config.yml 放在本项目目录而非默认位置，用：
> ```powershell
> cloudflared tunnel run --config "D:\demo\ERPGo_API版本\cloudflare\config.yml" erp-tunnel
> ```

（生产环境建议把 `cloudflared tunnel run erp-tunnel` 配成 Windows 服务或开机自启，
不要在命令行前台一直挂着。）

---

## 第七步：启动本机 ERP 系统

在你的本地服务器上启动 `启动器.py`（它会拉起前端 5173 + 后端 8000）。
隧道已把 `chinamxl.cc.cd` 指向本机 5173，因此系统即可通过公网访问。

浏览器打开：**https://chinamxl.cc.cd**

---

## 常见问题

1. **打开网址报错 / 连不上**
   确认本机 ERP 已启动（启动器.py 在跑）、隧道进程在运行、5173 端口可被本机访问。

2. **想改成生产构建（而非前端开发服务器 5173）**
   当前 config.yml 指向 `http://localhost:5173`（由启动器拉起，已内置 /api 代理）。
   若改为 `vite build` 后的静态目录，需自行用 nginx / 静态服务器托管 `dist`，
   并把 config.yml 的 `service` 改成对应地址与端口（同时把 /api 反向代理到 8000）。

3. **JSON 凭证文件丢失或想重建**
   重新执行第二步 `cloudflared tunnel create`（换个名字或先 `cloudflared tunnel delete`
   旧隧道），会重新生成一份新的 JSON 凭证。

4. **证书/凭证文件位置**
   默认都在 `C:\Users\Administrator\.cloudflared\` 目录下：
   - `cert.pem`：登录证书（第一步生成）
   - `<隧道ID>.json`：隧道凭证（第二步生成，部署必需）
   - `config.yml`：隧道配置（第四步放这里）
