# 电商产销协同管理系统（ERP_GO）

轻量级内网电商产销协同管理平台，面向「自有工厂 + 多网店/外贸」的经营场景，打通**销售端、工厂端、发货端、老板端**四条业务链路，替代线下表格管理。核心能力：网店自主管理、订单统一录入、唯一追溯码 + 二维码溯源、工厂统一打印、发货全流程维护、图片凭证存档、操作全程留痕、销售提成可视化。

> **典型流程**：网店产生订单 → 销售将订单信息录入系统 → 工厂按订单生产 → 发货人填写运单号 → 销售把运单号回填到对应购物平台。系统同时支持网店提现与提成发放管理。

## 功能特性

- **四类角色权限隔离**：老板端（全权限）、销售端、工厂端、发货端，按钮级 + 接口级双重鉴权。
- **唯一追溯码 + 二维码溯源**：下单自动生成 `order_id` 与二维码，扫码免登录查看核心信息。
- **订单全生命周期管理**：录入、编辑、发货状态维护（未发货/已发货/虚拟发货）、物流信息、操作留痕。
- **提成透明化**：提成金额 = 销售金额 × 提成比例 ÷ 100，销售端列表直接展示计算公式。
- **财务模块**：工资（提成）结算、网店账户提现。
- **图片凭证管理**：产品图 / 发货凭证 / 虚拟发货凭证 / 生产任务图，按类型与日期归档。
- **站内信通知**：发货状态变更、物流信息修改自动推送对应销售端。
- **数据备份与还原**：每日凌晨自动备份（保留 30 天）+ 老板端手动一键备份/还原。
- **手机端轻量作业页**：工厂 / 发货一线人员在手机上扫码定位、按角色改单、拍照上传。
- **智慧大屏 / 商品管理 / 数据统计 / 系统设置**等辅助模块。

## 角色与权限

系统固定四类角色；除老板端外，其余角色数据严格隔离、无交叉权限。

| 角色 | 数据查看范围 | 核心操作 | 禁止项（关键） |
| ---- | ------------ | -------- | -------------- |
| 老板端 | 全部数据（含所有提成、销售金额） | 所有功能：账号/权限、提成比例、备份还原、导出、二维码打印、强制审批 | 无 |
| 销售端 | 自有网店、自录订单及图片 | 网店/订单录入编辑、产品图、维护发货状态、查看本人提成 | 不可看他人订单、不可打二维码、不可改物流信息、不可管理账号 |
| 工厂端 | 所有状态订单（**隐藏销售金额/提成**）、全部图片 | 全量订单筛选、单/批量二维码打印、上传生产任务图 | 不可编辑订单、不可改物流、不可看金额/提成 |
| 发货端 | 自身关联订单（**隐藏金额/提成**）及图片 | 维护发货状态、填写物流、上传/删发货凭证、查看站内信 | 不可改订单主体、不可看金额/提成、不可打二维码 |

**通用规则**：
1. 网店已关联任意订单则禁止删除，提示「该网店已关联订单，无法删除」；关店后不可新增关联订单，已关联订单正常流转。
2. 图片全员可见，仅上传人可编辑/删除（老板端可强制删除并填原因）。
3. 除老板端、工厂端外严格数据隔离；工厂端可见全量订单但隐藏敏感字段。
4. 按钮级 + 接口级双重权限控制。
5. 所有核心操作（增删改、状态变更）均记录操作日志，不可删除/篡改，发货相关修改详细记录前后值。

## 核心业务模块

### 登录与系统管理
账号密码登录（Token 鉴权）、自主改密、老板端重置密码；登录日志与操作日志（可筛选导出）；每日自动备份 + 手动备份还原；系统参数配置（Token 有效期、二维码临时链接有效期、临时图清理时间、打印模板）。

### 用户管理（含提成比例）
老板端管理所有角色账号；仅老板端可设置销售端提成比例（整数 1–100，按百分比计算，实时生效）；账号可启用/禁用。

### 网店管理
字段：店铺名称（不可重复）、`shop_id`（明文主键，= 店铺名称）、状态（正常/关店）、创建人、时间。已关联订单禁止删除。

### 订单管理
- **录入字段**：追溯码 `order_id`（自动）、销售平台（关联自有网店）、商品名称、平台订单号（唯一）、销售金额、提成金额（自动算）、发货状态、物流公司/单号、收货地址、备注、产品图。
- **追溯码生成规则**：`登录账号 + 年月日(YYYYMMDD) + 网店ID + 6位随机数字`；后端预生成 1000 个随机号队列，SQLite 独占事务取号，冲突自动重试（≤3 次），队列 ≤100 时自动补满，保证并发无重复。
- **状态**：未发货 / 已发货（必填物流公司+单号+凭证）/ 虚拟发货（必填虚拟凭证）。
- **列表差异**：销售端展示提成金额与公式；工厂端隐藏金额/提成/操作人；发货端仅显自身关联订单的发货字段。

### 二维码管理
与 `order_id` 一一对应，扫码免登录看核心信息（点「查看详情」需登录，按角色过滤敏感字段）；仅老板端/工厂端可打印（单条/批量，适配 A4、不干胶，可自定义模板）。

### 发货管理
发货状态三类自由切换并满足约束；发货端维护自身关联订单的物流信息与凭证；每次变更记录日志并推送站内信给对应销售端。

### 财务模块
- **工资结算（提成结算）**：按发货时间统计各销售提成，支持批量/单个结算（标记 `commission_paid=true`），查看历史结算记录。
  - 接口：`GET /api/commission-settlement/unpaid`、`GET /api/commission-settlement/unpaid/orders`、`POST /api/commission-settlement/pay`
- **账户提现**：按创建者分组的网店提现记录，支持增删改查与 Excel 导出（仅老板端）。
  - 接口：`GET /api/withdraw/shops`、`GET|POST /api/withdraw/records`、`PUT|DELETE /api/withdraw/records/{id}`、`GET /api/withdraw/records/export`

### 图片管理（方案 A）
四类：`product`（产品图）/ `shipping`（发货凭证）/ `virtual`（虚拟发货凭证）/ `production`（生产任务图）。上传先入 `temp` 临时目录，确认提交后移至正式目录并按 `order_id_序号.后缀` 命名、按日期归档；每日凌晨清理超 24 小时临时图。支持 JPG/PNG/JPEG，单张 ≤5MB，拖拽/批量上传，仅上传人可编辑删除。

### 其他模块
站内信通知、智慧大屏、商品管理、数据统计、系统设置、汇率计算器等，详见 `开发文档说明.md`。

## 数据库核心表（共 12 张）

| 表名 | 作用 | 关键字段 |
| ---- | ---- | -------- |
| `user` | 账号 | id, username(唯一), password(MD5), role(boss/sales/factory/shipping), commission_rate(1–100), status |
| `shop` | 网店 | id, shop_id(主键), shop_name, shop_account, status(normal/closed), creator |
| `order` | 订单 | id, order_id(追溯码), shop_id, product_name, platform_order_no(唯一), sales_amount, commission_amount, commission_rate, shipping_status, logistics_company, logistics_no, shipping_operator, shipping_time, receiver_address, remark, creator |
| `image` | 图片 | id, order_id, image_type, image_path, image_name, uploader, upload_time |
| `operation_log` | 操作日志 | id, operator, operation_type, operation_module, operation_content(含前后值), ip_address |

> 其余表（物流公司、通知、统计、提成结算、提现、商品、大屏等）结构详见 `开发文档说明.md` 第 3.9 节。

## 接口规范

- **风格**：RESTful；GET 查询 / POST 新增 / PUT 编辑 / DELETE 删除；请求头统一携带 `Authorization: Bearer <Token>`。
- **返回格式**：统一 JSON `{ code, message, data }`。
- **状态码**：200 成功 / 400 参数错误 / 401 未登录或 Token 失效 / 403 权限不足 / 404 不存在 / 500 服务器错误。
- **鉴权**：除登录/登出外均需有效 Token；接口层按角色 + 数据权限拦截（越权返回 403，跨账号数据仅返回自身关联）。
- **文档**：后端自动生成 Swagger，访问 `/docs` 查看完整参数、示例与权限说明。

## 手机端轻量作业页（`/m/`）

与 PC 端同源托管于后端，无需额外部署。访问 `http://<服务器IP>:8000/m/`。

- **登录**：复用 PC 端 JWT 令牌。
- **扫码定位**：扫描订单二维码（内容为订单号）打开详情；支持摄像头实时扫码与「从相册选二维码」（HTTP 局域网下浏览器禁用摄像头时自动回落相册）。
- **按角色作业**：
  - 工厂端：查看基础信息，修改生产状态与订单备注，上传生产任务图；
  - 发货端：维护发货信息（物流公司/单号/状态）与备注，上传发货凭证；
  - 销售/管理端：查看完整信息并按权限操作。
- **说明**：兼容现有订单二维码，无需重印；完整管理功能仍在 PC 端；备份/还原入口集成在 Windows 启动器「⚙ 设置」视图。

## 启动与部署

### 环境要求
- Windows 10 及以上（32/64 位）；CPU ≥ i5、内存 ≥ 4GB、硬盘 ≥ 50GB。
- 内网环境即可，无需外网；Python/SQLite 已随启动器打包，无需手动配环境。

### 一键启动（推荐）
双击 `启动器.py` 或 `一键启动.bat` → 自动初始化数据库（建表、默认账号）、创建图片目录（`image_store`、`temp`）→ 启动前后端并打开登录页。启动器提供：服务状态指示、实时日志、底部「启动系统 / 停止系统 / 打开页面 / 刷新」按钮、⚙ 设置中的备份还原与自动备份计划。

### 手动启动
```bash
# 后端
cd backend
pip install -r requirements.txt
python run_server.py            # 或 start_backend.bat / start_backend.ps1

# 前端（开发模式）
cd frontend
npm install
npm run dev                     # 生产构建：npm run build（产物至 dist/）
```
数据库如需单独初始化：运行根目录 `数据库初始化.py`。

### 数据备份与维护
- 每日凌晨自动备份数据库与图片至 `backup/`，保留 30 天；老板端可手动一键备份（建议每周 1 次）。
- 系统更新：替换可执行文件/源码后直接启动，数据库与图片自动保留，无需重新初始化。
- 故障：无法启动检查目录完整性与磁盘空间；数据异常用备份还原；接口报错查操作日志与系统日志。
- 存储：定期清理 `temp` 临时目录与超期备份。

## 异常处理

| 类型 | 场景 | 处理 |
| ---- | ---- | ---- |
| 业务异常 | 订单重复录入、网店关联订单删除、提成比例越界、图片格式/大小超标 | 前端弹窗提示原因，后端返回 400，不影响系统运行 |
| 系统异常 | 数据库/存储失败、网络中断、并发冲突 | 记录错误日志，前端提示「系统异常，请联系管理员」，后端返回 500 |
| 权限异常 | 无权限、Token 失效、未登录 | 提示「权限不足 / 请重新登录」，后端返回 401/403 |
| 关键场景 | 追溯码冲突自动重试（≤3 次）；图片上传失败可重传；备份/还原失败提示并检查空间/文件合法性；状态切换不满足约束则阻止并提示原因 | 均记录日志，管理员可定位处理 |
